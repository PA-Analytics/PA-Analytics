# Pablo Alvarez Valencia

Economics student at UAM, Mexico. I build data tools and explore how people and AI agents can work together.

My public projects connect two interests: understanding data with Python and turning goals into interactive software with TypeScript.

## Selected work

### [TRAZO — Agentic learning](https://github.com/PA-Analytics/trazo-programs)
An agentic learning platform that turns learning goals into an interactive quest map.

TypeScript · Google Cloud · Gemini

### [TRAZO Quest — Human + agent workspace](https://github.com/PA-Analytics/trazo-quest-webmcp)
A shared visual workspace where agents propose paths, humans approve structural changes, and evidence earns progress. Built around WebMCP.

TypeScript · WebMCP

### [Crypto Market Monitor](https://github.com/PA-Analytics/crypto-market-monitor)
A Python tool that fetches cryptocurrency prices from CoinGecko and stores timestamped market data in CSV files for analysis.

Python · REST APIs · CSV
